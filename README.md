# База даних інтернет-магазину

## Функціональність

- Створення бази даних для інтернет-магазину.
- Реалізація п’яти основних таблиць:
  - `users` — користувачі;
  - `products` — товари;
  - `orders` — замовлення;
  - `categories` — категорії;
  - `reviews` — відгуки.
- Визначення зв’язків типу **один-до-багатьох**:
  - один користувач може мати багато замовлень;
  - один користувач може залишити багато відгуків;
  - один товар може мати багато відгуків.
- Визначення зв’язків типу **багато-до-багатьох**:
  - товари та категорії через таблицю `product_categories`;
  - замовлення та товари через таблицю `order_products`.
- Додавання первинних ключів `PRIMARY KEY`.
- Додавання зовнішніх ключів `FOREIGN KEY`.
- Додавання обмежень `CHECK`, `UNIQUE`, `NOT NULL`.
- Додавання тестових даних для перевірки роботи бази даних.
- Додавання прикладів SQL-запитів для перегляду даних.

## Запуск проєкту

Встановити PostgreSQL.

Створити базу даних і таблиці:

```bash
psql -U postgres -f schema.sql
```

Підключитися до створеної бази даних:

```bash
psql -U postgres -d online_shop_db
```

Додати тестові дані:

```bash
psql -U postgres -d online_shop_db -f seed.sql
```

Запустити приклади запитів:

```bash
psql -U postgres -d online_shop_db -f queries.sql
```

## Опис таблиць

### users

Таблиця зберігає дані користувачів інтернет-магазину.

Основні поля:

- `user_id` — первинний ключ;
- `full_name` — повне ім’я користувача;
- `email` — електронна пошта;
- `phone` — номер телефону;
- `address` — адреса користувача.

### products

Таблиця зберігає інформацію про товари.

Основні поля:

- `product_id` — первинний ключ;
- `name` — назва товару;
- `description` — опис товару;
- `price` — ціна товару;
- `stock_quantity` — кількість товару на складі.

### orders

Таблиця зберігає замовлення користувачів.

Основні поля:

- `order_id` — первинний ключ;
- `user_id` — зовнішній ключ на таблицю `users`;
- `order_date` — дата створення замовлення;
- `status` — статус замовлення;
- `total_amount` — загальна сума замовлення.

### categories

Таблиця зберігає категорії товарів.

Основні поля:

- `category_id` — первинний ключ;
- `name` — назва категорії;
- `description` — опис категорії.

### reviews

Таблиця зберігає відгуки користувачів на товари.

Основні поля:

- `review_id` — первинний ключ;
- `user_id` — зовнішній ключ на таблицю `users`;
- `product_id` — зовнішній ключ на таблицю `products`;
- `rating` — оцінка товару від 1 до 5;
- `comment` — текст відгуку.

## Зв’язки між таблицями

### Один-до-багатьох

```text
users 1 --- * orders
users 1 --- * reviews
products 1 --- * reviews
```

### Багато-до-багатьох

```text
products * --- * categories
orders * --- * products
```

У реляційній базі даних зв’язок **багато-до-багатьох** реалізовано через службові таблиці:

```text
product_categories
order_products
```
